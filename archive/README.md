# Historical Experiments

This directory preserves superseded work for later reference. Nothing here is
part of the active import path, test suite, CLI, or research claim.

## Contents

| Directory | Historical material |
| --- | --- |
| `code/` | Early v2, single-reader/feeder, static-zone v1, Zipf workload, and artificial skew modules |
| `configs/` | Matching historical JSON configurations |
| `scripts/` | Earlier sweep, plotting, and analysis entry points |
| `tests/` | Tests tied to archived models |
| `research/` | Earlier virtual-zone narrative and batch-skew presentation |
| `results/` | Local generated outputs; intentionally ignored by Git |

The code snapshots retain their original imports and paths. Restore a complete
experiment family into a branch before running it; archived modules are
reference material, not a supported second implementation.
